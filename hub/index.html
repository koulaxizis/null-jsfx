The tour

Library

Every plugin, one place

All 174 plugins with their interface, the formats each one comes in and what is already on your computer.

  • JSFX and GFX for REAPER, VST3, CLAP, LV2 on Linux, AU on macOS
  • One by one, a whole group, or everything
Search

Find what you need

Search by name or by what you need: eq, reverb, vocal, drums. The list narrows as you type.

Install

One click

Install puts a plugin in every format picked in the bar, in the folders your DAW reads. Only the files it needs are downloaded.

  • Checks every download against the release
  • Check and repair, roll back, the same set on another computer
Plugin page

Video, demo and guide

Each plugin has its page: the presentation video, a before-and-after listen, its controls and factory presets, and each format on its own.

Profiles

Starter profiles

Podcast, Beatmaking, Mixing, Mastering, Guitar and Sound Design: ready-made sets of plugins and extras, installed with one button.

Extras

The Rack, chains and more

Turn on the Rack, the 89 FX chains, the factory presets, the tablet remote and the font, each on its own.

Privacy

No account, no tracking

It only reads the release list from GitHub. Updates are checked once a day, with one notice per release, and it can start in the tray.

  • English and Greek
  • Uninstall everything in one step

How an update reaches you

Three steps

  1. DownloadThe Hub for Windows (setup), Linux (AppImage or .deb) or macOS (.dmg).
  2. PickChoose the formats once, then the plugins, a group or a starter profile.
  3. PlayOpen your DAW: the plugins are there. The Hub tells you when there is a new version.
