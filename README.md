# NULL JSFX — Audio Without Noise

24 professional audio effects for Cockos Reaper. Pure EEL2 scripting, native sliders, zero dependencies. Free and open source.

## Plugins

| Category | Plugins |
|----------|---------|
| **EQ / Filters** | 5-Band Parametric EQ, Filter (TPT SVF) |
| **Utility** | Channel Utility, Stereo Width, Click Repair |
| **Saturation** | Tape Saturation, Harmonic Drive, Distortion, Bit Crush |
| **Time Modulation** | Chorus, Flanger, Phaser, Vibrato, Tremolo, Auto Pan, Ring Mod |
| **Dynamics** | Gate, Dynamics (Compress/Expand), Limiter (Limiter/Clipper/Brickwall) |
| **Time Based** | Delay, Reverb |
| **Specialized** | DeEsser, Pitch Shifter, Transient Shaper |

## Installation

1. Download the latest release from [GitHub Releases](https://github.com/koulaxizis/null-jsfx/releases)
2. Extract the `null-jsfx` folder to your Reaper Effects directory:

   | OS | Path |
   |----|------|
   | **Windows** | `C:/Users/[Username]/AppData/Roaming/REAPER/Effects/` |
   | **macOS** | `~/Library/Application Support/REAPER/Effects/` |
   | **Linux** | `~/.config/REAPER/Effects/` |

3. Restart Reaper or re-scan plugin folders
4. Find plugins under **JS: NULL JSFX** in the FX browser
