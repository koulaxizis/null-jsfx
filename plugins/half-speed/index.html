HALF SPEED

Real-Time Halftime & Slow-Down

Controls

  • Length1/4 / 1/2 / 1 Bar / 2 Bars — How much input is captured per cycle: a 1/4 or 1/2 note, 1 Bar or 2 Bars at the host tempo.
  • Speed1/2 / 1/4 / 2/3 — Playback speed of the captured audio: 1/2 is classic halftime (an octave down), 1/4 a quarter speed (two octaves down), 2/3 a lazier drag; one cycle lasts Length / Speed.
  • Pitch KeepOff / On — Off slows the audio like a tape (lower pitch); On uses overlapping 40 ms grains so only the tempo halves and the pitch stays the same.
  • Tone1000 to 20000 Hz — High cut on the slowed signal (1 to 20 kHz) to tame the dull or grainy top end; 20 kHz is off.
  • Mix0 to 100% — Blend of slowed and dry signal.
  • Sync Offset0 to 3 beats — Shifts the cycle start by 0 to 3 beats from the bar line while the transport plays.

Best uses

  • Instant halftime drops and breakdowns on drums or full mixes
  • Octave-down slowed-tape textures on vocals and synths
  • Quarter-speed drones and pads from any loop
  • Pitch-kept halftime grooves that stay in key
  • Transitions that drag the beat before the next section

Properties

Signal chain: Input → cycle buffer (one cycle = Length / Speed; the first Length of each cycle is recorded) → read from the cycle start at Speed (linear interpolation) or, with Pitch Keep, two Hann grains of ~40 ms half a grain apart that follow the slowed read point at the original pitch → 5 ms crossfade at every new cycle → one-pole high cut (Tone) → Mix with the dry signal → Output. While the transport plays, the cycle is locked to the song position (bar line + Sync Offset); stopped, it free-runs at the host tempo (40 to 300 bpm). No latency is reported: the slowed output is a musical effect, not a delay to compensate.
