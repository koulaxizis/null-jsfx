Controls

  • KeyC / C# / D / D# / E / F / F# / G / G# / A / A# / B — Key (root note) of the scale the voice is tuned to
  • ScaleChromatic / Major / Minor / Harmonic Minor / Pentatonic Major / Pentatonic Minor / Blues / Dorian / Mixolydian — Scale of allowed notes: Chromatic, Major, Minor, Harmonic Minor, Pentatonic Major/Minor, Blues, Dorian or Mixolydian
  • Retune Speed0 to 400 ms — How fast the pitch glides to the target note: 0 ms = hard, stepped “robot” tuning; higher = gentler, more natural
  • Humanize0 to 100% — Share of the singer's own fast pitch movement (vibrato) kept around the corrected note
  • Transpose−12 to +12 semitones — Extra pitch shift in semitones, applied after the correction (formants stay in place)
  • Sensitivity0 to 100% — Pitch detection threshold: higher counts more of the signal as pitched (breathy voices), lower ignores noisy parts
  • Mix0 to 100% — Dry/wet blend (the dry signal is delayed to stay in time)
  • TargetScale / MIDI — What the voice is tuned to: the nearest note of Key and Scale, or the latest held MIDI note (falling back to the scale when no note is held)
  • Vibrato Rate0 to 10 Hz — Speed of the added vibrato
  • Vibrato Depth0 to 100 cents — Width of the added vibrato, which fades in on every new note (0 = off)

Best uses

  • Transparent tuning of lead and backing vocals
  • Hard-tune “T-Pain” robot vocal effect (Retune 0 ms)
  • Forcing a vocal or monophonic instrument onto a key and scale
  • Formant-preserving transposition of a sung line

Properties

Signal chain: Input → mono 50 Hz high-pass + 1.2 kHz 4th-order low-pass, decimated to ~11 kHz → YIN pitch tracker (70 Hz to 1 kHz, new estimate every ~6 ms, Sensitivity = threshold) → nearest Key/Scale note with hysteresis → Retune glide + Humanize (vibrato kept) → TD-PSOLA shifter (peak-aligned pitch marks, two-period Hann grains, formants preserved; stereo kept) → Dry/Wet Mix → Output. Monophonic sources only; unvoiced sounds pass with the transpose only; latency about 39 ms, reported to the host (PDC).
