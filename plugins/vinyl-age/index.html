VINYL AGE

Vintage Vinyl Degrader

Listen

The same music with the Subtle Warmth preset and without the plugin. Switch while it plays.

Controls

  • Wow0 to 100% — Slow pitch drift (0.5 Hz delay modulation)
  • Flutter0 to 100% — Fast pitch wobble (6 Hz delay modulation)
  • Crackle0 to 100% — Amount and rate of random crackle pops
  • Noise Level0 to 100% — Background hiss level
  • Bit Depth4 to 16 — Quantisation bit depth
  • Sample Rate2000 to 44100 Hz — Sample-and-hold rate reduction
  • Lowpass Freq1000 to 20000 Hz — Cutoff of the 12 dB/oct lowpass
  • Mix0 to 100% — Dry/wet blend (the dry signal is delayed to stay aligned with the wet path)
  • RPM33 / 45 / 78 — Turntable speed: sets the wow rate (33 keeps the 0.5 Hz drift, 45 and 78 run it faster), and 78 adds the narrow-band tone of a shellac disc.
  • Scratches0 to 100% — Sparse, louder clicks and pops (a sharp tick with a softer thump) at random intervals, separate from the Crackle.
  • MonoOff / On — Folds the processed record signal to mono, like an old mono pressing.

Best uses

  • Lo-fi hip-hop and chillout textures
  • Make samples sound like old records
  • Nostalgic, worn character on pianos and vocals
  • Degraded radio or memory effects

Properties

Signal chain: Input → Wow/Flutter Modulated Delay (50 ms centre) → Bitcrush → Downsample → 2-Pole Lowpass → Crackle → Noise → Mix → Output. The dry signal is delayed by the same 50 ms so any Mix setting blends in phase (no slapback); the 50 ms latency is reported to the host for delay compensation.
