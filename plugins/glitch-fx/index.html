Controls

  • Rate0.1 to 20 Hz — How often a new glitch event starts (events per second)
  • Stutter Length1 to 64 1/x notes — Length of the captured slice as a note value (1/x) at the project tempo (120 BPM if none)
  • StutterOFF / ON — Loops the latest slice until the next event; off lets the other effects work on the live signal
  • Gate Depth0 to 100% — Attenuation applied to the second half of each gate cycle
  • GateOFF / ON — Enables the rhythmic gate chop
  • Pitch Shift−24 to +24 semitones — Playback pitch of the loop in semitones (varispeed)
  • Pitch ShiftOFF / ON — Enables Pitch Shift
  • Reverse Chance0 to 100% — Probability that an event plays its slice backwards
  • ReverseOFF / ON — Enables random reversal: reverses the stutter loop, or with Stutter off plays the live audio back in reversed chunks
  • Tape Stop Time10 to 1000 ms — How long a tape-stop event takes to slow to a halt
  • Tape StopOFF / ON — Enables tape stops, triggered on about 30% of events
  • Grain Size10 to 500 ms — Length of the Hann-windowed grain looped instead of the full slice
  • GranularOFF / ON — Loops a short windowed grain instead of the whole slice, or with Stutter off turns the live signal into overlapping grains
  • Mix0 to 100% — Dry/wet blend
  • TriggerAuto / MIDI — What plays the effects: Auto rolls them at Rate with the switches and chances, MIDI plays them while notes C3 to F3 are held (Stutter, Gate, Pitch Shift, Reverse, Tape Stop, Granular) with the velocity setting how much is mixed in

Best uses

  • Beat-repeat and stutter fills on drums
  • Random reverse and tape-stop transitions
  • Granular buzz and freeze textures on vocals
  • Chopped, gated rhythmic effects on pads
  • Live performance glitching via automation

Properties

Signal chain: Input → 4 s Ring Buffer → Event Clock (Rate) → Slice Loop (Stutter / Granular grain, Reverse, Pitch, Tape Stop) or, with Stutter off, live processing (reversed chunks, two overlapping Hann grains, varispeed pitch / tape stop) → Gate → Mix → Output. Every effect works on its own; slice length follows host tempo; loop seams get 3 ms fades; zero latency.
