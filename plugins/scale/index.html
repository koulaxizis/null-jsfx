Controls

  • KeyC / C# / D / D# / E / F / F# / G / G# / A / A# / B — The key of the scale.
  • ScaleMajor / Minor / Harmonic Minor / Melodic Minor / Dorian / Phrygian / Lydian / Mixolydian / Locrian / Major Pentatonic / Minor Pentatonic / Blues — The scale every note is fitted to: major, natural, harmonic or melodic minor, the modes (Dorian to Locrian), major or minor pentatonic, or blues.
  • ModeNearest / Up / Down / White Keys / Filter — How a note outside the scale is fixed: moved to the Nearest scale note (ties go down), always Up or always Down, dropped (Filter), or White Keys, where C, D, E, F, G, A and B play the scale's degrees from the key and the black keys are silent.
  • Transpose−12 to +12 st — Moves the incoming notes by semitones before they are fitted to the scale, so the result stays in key (in White Keys mode it moves what the keys play).
  • Octave−3 to +3 — Moves the result up or down by octaves (-3 to +3).

Best uses

  • Never hit a wrong note: every key snaps into the song's key
  • Play any scale on the white keys alone, in any key
  • Clean up MIDI from a controller or a pitch-to-MIDI converter
  • Drop out-of-key notes from generated or recorded parts
  • Quick transposition and octave shifts that stay in key

Properties

A MIDI effect: MIDI in, MIDI out, the audio passes through untouched (place it before an instrument). Every note is mapped once, when it starts; its note-off always ends the very note that was sent, even when the settings change while it is held, and a note two keys share sounds until both are released. All notes off (CC 120/123) releases every key of its channel; pitch bend, controllers, sustain and pressure pass through (poly pressure follows the mapped note). Sample-accurate and the same in the JSFX, the GFX version and the VST3/CLAP.
