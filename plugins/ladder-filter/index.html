LADDER FILTER

Moog-Style Ladder Filter

Listen

The same music with the Warm Bass Lowpass preset and without the plugin. Switch while it plays.

Controls

  • Cutoff20 to 20000 Hz — Filter cutoff frequency
  • Resonance0 to 4 — Feedback around the ladder; high values approach self-oscillation (capped at 3.95)
  • Drive0 to 100% — Input gain into the saturating ladder for analog growl (level-compensated)
  • ModeLowpass / Highpass — Lowpass or Highpass 24 dB/oct response
  • Gain−12 to +12 dB — Output level

Best uses

  • Classic resonant synth filter sweeps
  • Warm, driven lowpass on drums and bass
  • Automated filter build-ups
  • Highpass sweeps with resonant peak
  • Taming harsh digital sources with analog character

Properties

Signal chain: Input → Drive → 4-Pole Zero-Delay-Feedback Ladder (24 dB/oct, tanh saturation in the loop) → LP / HP Output → Gain → Output. Stable and in tune up to 20 kHz at full resonance; stereo channels independent, zero latency.
