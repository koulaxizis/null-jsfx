Modulated Degrading Delay

Controls

  • Time1 to 1000 ms — Base delay time
  • Mod Rate0.1 to 10 Hz — Speed of the LFO wobbling the delay time
  • Mod Depth0 to 50 ms — Amount of delay time modulation (limited to the delay time)
  • Feedback0 to 99% — Amount of the repeats fed back
  • Distortion0 to 100% — Saturation inside the feedback loop (level-compensated)
  • FilterOff / LP / HP / BP — Filter type inside the loop: Off, LP, HP or BP
  • Filter Freq100 to 20000 Hz — Filter cutoff / centre frequency
  • Mix0 to 100% — Dry/wet blend

Best uses

  • Warbly tape-style echoes
  • Dub delays that darken and distort as they repeat
  • Wide, wobbling stereo delays on guitars
  • Lo-fi textures on vocals and synths

Properties

Signal chain: Input → Modulated Delay Line → Filter → Saturation (tanh) → Feedback → Mix → Output. Right-channel LFO runs a quarter cycle behind the left for width; repeats degrade on each pass; max 1 s delay, zero latency.
