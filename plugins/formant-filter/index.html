FORMANT FILTER

Vowel Formant Filter

Listen

The same music with the Talking Synth Ah preset and without the plugin. Switch while it plays.

Controls

  • VowelA / E / I / O / U — Selects the vowel shape (A, E, I, O, U), which sets the three formant centre frequencies
  • Gain−12 to +12 dB — Output level of the summed formant bands
  • Q5 to 20 — Bandwidth of each formant band; higher Q gives narrower, more vocal peaks

Best uses

  • Make synths and pads “talk” with vowel colours
  • Add vocal character to drums, noise or guitar
  • Automate Vowel for talking-filter sweeps
  • Sound design for creatures and robotic voices

Properties

Signal chain: Input → 3 parallel RBJ Band-Pass Filters (F1, F2, F3 per vowel, e.g. A = 730 / 1090 / 2440 Hz) → Sum ×3 → Gain → Output. Stereo channels processed independently. Filter state is never reset and the formants glide (~15 ms) to a new vowel, so Vowel, Gain and Q can be automated without clicks.
