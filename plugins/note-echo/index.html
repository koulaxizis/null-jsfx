NOTE ECHO

MIDI Delay for Notes

Download free Part of NULL JSFX 3.0: 150 plugins, free and open source (MIT). Easiest with NULL JSFX Hub.

Controls

  • Repeats1 to 16 — How many times each note is played again.
  • Time10 to 2000 ms — Time between echoes when Tempo Sync is Off.
  • Tempo SyncOff / On — On uses Subdivision at the host's tempo.
  • Subdivision1/4 / 1/8 / 1/16 / 1/32 / 1/2 / 1/8T / 1/16T / 1/8D — Time between echoes when Tempo Sync is On.
  • Velocity Decay0 to 100% — How much quieter each echo is than the one before.
  • Pitch Step−12 to +12 semitones — How far each echo moves in pitch (they stop past note 0 or 127).
  • Gate5 to 95% — How long each echo lasts, as a share of the time between echoes.
  • DryOff / On — Off leaves out the notes that come in, so only the echoes sound.

Best uses

  • Echoes that any instrument can play, without an audio delay
  • Rising or falling note cascades
  • Ratchets and rolls on drums
  • Generative patterns from a few notes

Properties

MIDI in → every note-on adds Repeats echoes to a time-sorted queue (velocity x (1 - Decay)^k, pitch + k x Pitch Step, Gate of the interval) → notes out; a note that starts again while it sounds is ended first. Other MIDI passes through at its own sample; all notes off drops that channel's echoes. Audio passes through.
