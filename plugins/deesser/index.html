DEESSER

Split-Band Sibilance Control

Download free Part of NULL JSFX 4.1.1: 174 plugins, free and open source (MIT). Easiest with NULL JSFX Hub.

Listen

Live: the plugin itself runs in your browser on a loop of NULL JSFX instruments. Change the preset or bypass it while it plays.

Controls

  • Target4000 to 10000 Hz — Centre frequency of the band-pass that isolates the sibilance.
  • Reduction−18 to 0 dB — Maximum cut applied to that band when sibilance gets loud.
  • ModeSplit / Wide — Split turns down only the sibilance band; Wide turns down the whole signal by the same amount.
  • Threshold ModeAuto / Manual — Auto uses the built-in detection level; Manual uses the Threshold control instead.
  • Threshold−60 to 0 dB — Level of the sibilance band above which the reduction starts (Manual only).
  • Range−18 to 0 dB — Caps how far the signal is turned down, while Reduction sets how quickly it gets there (-18 dB = no cap).
  • ListenOff / On — Plays only what is being removed, to tune Target and the threshold by ear.
  • Suppress Freq0 to 16000 Hz — Centre of the band that is turned down (0 = the Target frequency, as before)
  • Suppress Q0.5 to 8 — Width of the suppress band (narrow at 8, wide at 0.5)
  • Suppress ShapeBand / Shelf — Band turns down a band around Suppress Freq; Shelf turns down everything above it

Best uses

  • Taming harsh S, T and Ch sounds on vocals
  • Softening sibilant voice-over and podcast speech
  • Reducing hissy cymbal splash on overheads
  • Controlling brittle highs on bright acoustic guitar

Properties

Input → band-pass at Target (Q 2) → stereo-linked envelope follower (0.5 ms attack, 60 ms release) → band attenuation above a fixed −30 dB threshold, reaching full Reduction 12 dB above it → Output. Only the sibilant band is turned down; zero latency. The suppress band can differ from the detect band: detect the sibilance at one frequency, turn down another band or a high shelf.
