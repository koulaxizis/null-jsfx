GLUE COMP

Stereo Bus Compressor

Download free Part of NULL JSFX 2.8: 133 plugins, free and open source (MIT). Easiest with NULL JSFX Hub.

Controls

  • Threshold−40 to 0 dB — Level above which the compressor starts to work (4 dB soft knee around it).
  • Ratio2 / 4 / 10 — Compression ratio: 2:1 for gentle glue, 4:1 for control, 10:1 for heavy squash.
  • Attack0.1 ms / 0.3 ms / 1 ms / 3 ms / 10 ms / 30 ms — How fast the gain reduction sets in; slower attacks let transients through.
  • Release0.1 s / 0.3 s / 0.6 s / 1.2 s / Auto — How fast the gain recovers; Auto follows the program (fast after peaks, slow under dense passages).
  • Makeup0 to 20 dB — Gain after compression.
  • Mix0 to 100% — Blend between the dry and the compressed signal (parallel compression).
  • Sidechain HPF0 to 300 Hz — High-pass on the detector only, so bass does not pump the mix (0 = off).

Best uses

  • Gluing a mix bus together
  • Punchy drum bus compression
  • Parallel (New York) compression
  • Gentle control on a master or a group

Properties

Input → key (optional one-pole high-pass) → stereo-linked peak detector → gain computer (2/4/10:1, 4 dB soft knee) → smoothing in dB (stepped attack 0.1–30 ms, release 0.1–1.2 s or Auto: the deeper of an 80 ms and a 0.5 s / 1.5 s envelope) → Makeup → Dry/Wet Mix → Output. Zero latency.
