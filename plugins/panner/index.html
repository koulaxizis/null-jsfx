PANNER

Natural Stereo Placement

Download free Part of NULL JSFX 2.8: 133 plugins, free and open source (MIT). Easiest with NULL JSFX Hub.

Listen

The same music with the Hard Left Balance preset and without the plugin. Switch while it plays.

Controls

  • Pan−100 to +100 — Position of the source from hard left (-100) through centre (0) to hard right (100).
  • ModeBalance / Natural / Haas — Balance: plain L/R balance. Natural: a head model with interaural delay, level difference and head-shadow filtering on the far ear. Haas: the far ear hears the source later (precedence effect).
  • Width0 to 200% — Stereo width of the source itself: 0% = mono, 100% = unchanged, 200% = twice as wide.
  • Haas Delay1 to 30 ms — Delay of the far ear in Haas mode at full pan (scaled by the pan amount).
  • Output−24 to +12 dB — Output level.

Best uses

  • Placing mono instruments naturally in a mix, without the hole-in-the-middle of plain panning
  • Positioning stereo sources while keeping their own image
  • Haas-style wide placement of guitars and synths
  • Headphone-friendly panning

Properties

Input → Mid/Side (Side × Width) → Mid placed per ear: fractional delay (Woodworth ITD up to ~0.66 ms, or Haas Delay) → first-order high-shelf head shadow (to -8 dB above ~1.8 kHz) → constant-power gains; Side added back → Output. All changes glide over 20 ms. Zero latency.
