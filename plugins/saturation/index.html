Seven-Mode Saturation

Controls

  • Drive0 to 100% — Input gain into the saturation stage (up to 4x); in Bitcrush mode it also lowers the bit depth from 8 to 2 bits, in Fold mode it also adds folds.
  • Tone−12 to +12 dB — Tilt EQ on the saturated signal around 800 Hz: negative values darken (lows up, highs down), positive values brighten; 0 dB is flat.
  • Mix0 to 100% — Blend between dry and saturated signal.
  • ModeTape / Tube / Overdrive / Fuzz / Bitcrush / Waveshaper / Fold — Saturation curve: Tape, Tube, Overdrive, Fuzz, Bitcrush, Waveshaper (hard wavefolding) or Fold (sine wavefolder; Drive sets the fold depth).
  • Input−12 to +12 dB — Gain into the saturation stage before Drive, in dB; 0 dB is off.
  • Output−24 to +12 dB — Output level after the dry/wet mix, in dB; 0 dB is off.
  • OversamplingOff / 2x / 4x — Runs the saturation at 2x or 4x the sample rate (linear-phase halfband filters, 31 or 37 samples of latency) so its harmonics do not fold back as aliasing; Off adds no latency.
  • Emphasis−12 to +12 dB — Tilt EQ around 800 Hz before the saturation and its exact inverse after it: positive values make the highs distort more, negative values the lows, while the clean tone stays the same; 0 dB is off.
  • ChannelsStereo / Mid / Side — Channels: Stereo works on the whole signal; Mid or Side processes only that half of the mid/side pair and leaves the other untouched.
  • FocusOff / Bass / Mid / Presence — Focus: a +9 dB bell (Bass 100 Hz, Mid 1 kHz, Presence 3 kHz) before the saturation and its exact inverse after it, so that band distorts more while the clean tone stays the same; Off adds nothing.
  • Density0 to 100% — Density: thickens the curve so quieter parts of the wave saturate too, for a denser, more compressed sound; 0 % is off.

Best uses

  • Warmth and density on buses
  • Fuzz and overdrive on guitars and bass
  • Bit-crushed lo-fi textures
  • Wavefolded synth tones

Properties

Input → Drive → selected curve (Fold: a sine wavefolder whose depth grows with Drive) → Tone tilt EQ (one-pole split at 800 Hz, ±Tone/2 dB on each side) on the wet signal → Dry/Wet Mix → Output. No oversampling; zero latency.
