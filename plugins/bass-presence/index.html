BASS PRESENCE BETA

Bass You Can Hear on Small Speakers

Beta: its rules have been tested on test signals so far and may still be tuned from your feedback, so a project saved now can sound a little different after an update.

Controls

  • Amount0 to 100 — How much of the bass's harmonics is added (0% = off)

Best uses

  • Make a bass line readable on laptops, phones and earbuds
  • Add growl to a sub-heavy 808 without more low end
  • Check that a mix's low end still reads on small speakers
  • A gentle lift of the bass on the mix bus

Properties

Signal chain: Input → mono lows below 120 Hz (two RBJ low-passes) → a curve that makes odd and even harmonics → only the harmonics (two 180 Hz high-passes and an 1.8 kHz low-pass) → added to both channels. The dry signal is untouched, so the real low end stays as it is; 0% is a bypass. Stereo, zero latency.
