SNAPPY

One-Knob Transient Shaper

Download free Part of NULL JSFX 3.0: 150 plugins, free and open source (MIT). Easiest with NULL JSFX Hub.

Listen

The same music with the Snare Crack preset and without the plugin. Switch while it plays.

Controls

  • Amount0 to 100 — Transient emphasis: 0 is unity, 100 boosts detected attacks by up to +9 dB and trims the sustain by up to -3 dB

Best uses

  • Add snap to snares and kicks
  • Sharpen percussion loops
  • Punch on a drum bus
  • Bite on plucked instruments
  • Tighten roomy drum recordings

Properties

Input → stereo-linked level → fast (1 ms) and slow (25 ms) attack envelopes, 80 ms release → transient amount from their difference → gain between -3 and +9 dB scaled by Amount → Output. Zero latency, no look-ahead.

Formats

  • JSFXJSFX for REAPER, with REAPER's own sliders
  • GFXJSFX GFX for REAPER, with its own interface
  • VST3VST3 for any DAW
  • CLAPCLAP for any DAW
  • LV2LV2 for Linux DAWs such as Ardour, Carla and Qtractor
