NOISE GENERATOR

White, Pink & Brown Noise

Download free Part of NULL JSFX 2.7: 113 plugins, free and open source (MIT). Easiest with NULL JSFX Hub.

Controls

  • TypeWhite / Pink / Brown — Noise colour: White (flat), Pink (−3 dB/oct) or Brown (−6 dB/oct).
  • Level−60 to 0 dB — Output level of the noise.
  • Stereo Width0 to 100% — Correlation between channels: 0% = identical mono noise, 100% = fully independent left and right.
  • Low Cut20 to 2000 Hz — High-pass filter on the noise (12 dB/oct); 20 Hz is off.
  • High Cut500 to 20000 Hz — Low-pass filter on the noise (12 dB/oct); 20 kHz is off.
  • Follow Input0 to 100% — Makes the noise level follow the input's envelope, so it breathes with the track (100% = silent when the input is silent); 0% keeps it constant.
  • Ducking0 to 100% — Pushes the noise down while the input is loud and lets it back up in the gaps; 0% is off.
  • Mix ModeReplace / Add — Replace outputs the noise alone (the input is only used for Follow Input and Ducking), Add layers the noise on top of the input.

Best uses

  • Gain staging and monitor calibration
  • Testing filters and EQs
  • Sound design layers for risers and sweeps
  • Masking or ambience beds

Properties

Random generator → colour filter (Pink: multi-pole filter bank; Brown: leaky integrator) → Level → Stereo Width → Output. The input is replaced by the noise, not mixed with it.
