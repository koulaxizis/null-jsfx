GATE

Noise Gate with Sidechain HPF

Download free Part of NULL JSFX 2.9: 137 plugins, free and open source (MIT). Easiest with NULL JSFX Hub.

Controls

  • Threshold−60 to 0 dB — Level the signal must exceed for the gate to open.
  • Attack1 to 100 ms — How fast the gate opens.
  • Release50 to 1000 ms — How fast the gate closes once the signal drops.
  • Sidechain HPF0 to 500 Hz — High-pass on the detector only, so low-end rumble or bleed does not open the gate (0 = off).
  • Range−80 to 0 dB — How far the gate turns the signal down when closed: −80 dB closes fully, higher values only duck it (0 dB = no gating).
  • Hold0 to 500 ms — How long the gate stays open after the signal drops below the threshold, before the release starts.
  • Lookahead0 to 10 ms — Delays the audio so the gate opens just before each hit and keeps the attack intact (adds that much latency; 0 = off).
  • SidechainInternal / External — Internal listens to the track itself; External listens to input channels 3/4 (sidechain key).
  • Sidechain LPF1000 to 20000 Hz — Low-pass on the detector only, so hi-hats or cymbals do not open the gate (20 kHz = off).
  • FlipOff / On — Turns the gate into a ducker: the signal is turned down by Range while the detector is above the threshold.
  • Tone Release0 to 100% — Tone Release: while the gate closes, the tail also gets darker, like an instrument dying away, instead of only quieter; 0 % is off.

Best uses

  • Removing noise between vocal phrases
  • Cutting bleed on tom and snare mics
  • Cleaning amp hiss between guitar parts
  • Tightening drum tails

Properties

Input → optional one-pole high-pass on the detector → stereo-linked peak envelope → open/close against Threshold with attack/release smoothing → closed gain set by Range → Output. Zero latency.
