ROOM TONE

Dialogue Gap Filler

Download free Part of NULL JSFX 3.1: 154 plugins, free and open source (MIT). Easiest with NULL JSFX Hub.

Controls

  • LearnOff / On — While On, learns the room tone per frequency and between the channels: play a passage of room tone only, then switch Off
  • Threshold−80 to −20 dB — The input level below which a gap begins
  • Fill Level−20 to +6 dB — Level of the fill against the learnt room tone
  • Fade5 to 200 ms — How fast the fill fades in and out
  • Hold0 to 500 ms — How long the input must stay below Threshold before a gap is filled
  • ModeFill gaps / Constant bed — Fill gaps tops quiet passages up to the room tone; Constant bed adds the fill all the time
  • ListenOutput / Fill only — Hear the output or only the fill

Best uses

  • Fill the digital silence that cuts and gates leave in dialogue
  • Keep the room under a podcast steady after noise reduction
  • Lay a matching room bed under ADR recorded elsewhere
  • Bridge the gaps between edited takes from the same location

Properties

Signal chain: Learn: Input → 2048-Point FFT (4× overlap, Hann) → Power per Bin and Cross Spectrum. Fill: Learnt Magnitudes + Random Phases (Park-Miller) → IFFT Overlap-Add → Fill Level. Gap Detector (10 ms Power, Threshold, Hold) → Top-Up to the Room Tone → Fade → Output = Input + Fill. The fill never repeats, keeps the stereo coherence of the recording and adds only what is missing, so a gap that still holds its room tone gets nothing; no latency. The profile lives in memory and is not saved with the project: learn again after a reload.
