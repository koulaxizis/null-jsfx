TILT

One-Knob Tilt EQ

Download free Part of NULL JSFX 2.9: 137 plugins, free and open source (MIT). Easiest with NULL JSFX Hub.

Listen

The same music with the Vintage Dark preset and without the plugin. Switch while it plays.

Controls

  • Amount−100 to +100 — Bipolar tilt around 700 Hz: positive values brighten (treble up, bass down), negative values darken, up to ±6 dB each side; 0 is flat

Best uses

  • Quick tonal balance on a mix bus
  • Darken harsh recordings
  • Brighten dull stems
  • Match the tone of two takes
  • Mastering tonal nudges

Properties

Input → 700 Hz one-pole split → low band × opposite gain of high band (±6 dB) → summed → Output. Zero latency, stereo channels processed independently.

Formats

  • JSFXJSFX for REAPER, with REAPER's own sliders
  • GFXJSFX GFX for REAPER, with its own interface
  • VST3VST3 for any DAW
  • CLAPCLAP for any DAW
  • LV2LV2 for Linux DAWs such as Ardour, Carla and Qtractor
