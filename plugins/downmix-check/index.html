DOWNMIX CHECK

Hear a Bed as 5.1, Stereo or Mono

Download free Part of NULL JSFX 2.8: 133 plugins, free and open source (MIT). Easiest with NULL JSFX Hub.

Controls

  • Bed5.1 / 7.1 / 7.1.4 — The bed coming in: 5.1, 7.1 or 7.1.4; the pins it does not use are ignored.
  • MonitorBed / 5.1 / Stereo Lo/Ro / Mono — What you hear: the Bed as it is, folded to 5.1, to stereo Lo/Ro, or to mono (Stereo and Mono play on L and R).
  • Center Mix−6 to 0 dB — The centre in the stereo fold (-6 to 0 dB, -3 dB as ITU-R BS.775).
  • Surround Mix−6 to 0 dB — The surrounds in the stereo fold (-6 to 0 dB, -3 dB as ITU-R BS.775).
  • Height Mix−6 to 0 dB — The tops folded into the ear-level speakers below them (-6 to 0 dB).
  • LFE Mix−60 to +10 dB — The LFE in the stereo fold, from -60 dB (Off, as BS.775 drops it) to +10 dB.
  • SoloOff / L / R / C / LFE / Ls / Rs / Lrs / Rrs / Ltf / Rtf / Ltr / Rtr — Plays one channel of the bed alone, through the same fold.
  • Output−24 to +12 dB — Gain on what you hear (-24 to +12 dB).

Best uses

  • Check that a surround mix still works on stereo and mono systems
  • Catch the stereo fold clipping before a delivery
  • Solo one channel of a bed to find a problem
  • Listen to a 7.1.4 mix on a 5.1 room

Properties

7.1.4 to 7.1: each top into the ear-level speaker below it. 7.1 to 5.1: side and rear summed at -3 dB. 5.1 to Lo/Ro: Lo = L + C x Center Mix + Ls x Surround Mix (+ LFE x LFE Mix), Ro likewise. Mono: (Lo + Ro) / 2. The display shows every channel of the bed, every output, and the fold's highest peak, so you see when the stereo fold would clip. Gains only: no filters, no latency. In REAPER set the track to 12 channels and route the pins to your bed. The player on this site plays pins 1 and 2 only.
