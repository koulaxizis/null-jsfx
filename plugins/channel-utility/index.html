CHANNEL UTILITY

Gain, Phase & Routing

Controls

  • Input PadNone / -6 / -12 — Fixed input attenuation of 0, −6 or −12 dB.
  • Input Gain−12 to +18 dB — Continuous input trim before all other stages.
  • Phase LeftNormal / Inverted — Inverts the polarity of the left channel.
  • Phase RightNormal / Inverted — Inverts the polarity of the right channel.
  • DC Block Freq10 to 100 Hz — Cutoff of the one-pole DC-blocking high-pass filter.
  • DC Block Mix0 to 100% — Blend between the unfiltered and the DC-blocked signal.
  • Balance Left−6 to +6 dB — Level offset for the left channel.
  • Balance Right−6 to +6 dB — Level offset for the right channel.
  • Solo LOff / On — Mutes the right channel so only the left is heard (takes priority over Solo R).
  • Solo ROff / On — Mutes the left channel so only the right is heard.
  • Mono CheckStereo / Mono — Sums both channels to mono on both outputs.
  • Output Gain−12 to +12 dB — Final level trim after all processing.
  • Hard LimitOff / On — Clips any sample above ±0.99 to protect the output.

Best uses

  • Gain staging at the start of a chain
  • Fixing polarity problems on multi-mic recordings
  • Removing DC offset from recordings
  • Checking mono compatibility and each side individually
  • Correcting left/right level imbalance

Properties

Input → Pad + Input Gain → Polarity L/R → DC Block (one-pole high-pass) → Balance L/R → Solo L/R → Mono Check → Output Gain → Hard Limit (±0.99) → Output. Zero latency.
