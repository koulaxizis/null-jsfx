  • Rate ModeSync / Free — Sync: steps follow the host tempo and lock to the bar grid while playing; Free: steps run at Free Rate
  • Step Length1/4 / 1/8 / 1/16 / 1/32 — Note value of one step in Sync mode (1/16 = classic trance gate)
  • Free Rate0.5 to 40 Hz — Steps per second in Free mode (8 Hz = 16ths at 120 BPM)
  • Attack1 to 100 ms — Time for the gate to ramp open
  • Release10 to 500 ms — Time for the gate to ramp closed
  • Gate Depth0 to 100% — How far closed steps are turned down (0% = no gating, 100% = silence)
  • Probability0 to 100% — Chance that an open step actually opens the gate (100% = always, as programmed); lower values thin the pattern out at random
  • Seed0 to 999 — Picks a different random variation; the same Seed always gives the same choices at the same song position

Best uses

  • Classic trance-gated pads and supersaws
  • Rhythmic chopping of sustained chords
  • Stutter-like patterns on vocals
  • Turning drones into sequenced rhythms

Properties

Signal chain: Input → 16-Step Sequencer → Linear Attack/Release Gain Ramp × Depth → Output. In Sync mode the step clock follows the host tempo and, while the transport plays, is read from the song position so step 1 lands on every bar; when stopped it free-runs at the host tempo. Free mode runs at a fixed rate in steps per second. Stereo-linked, zero latency.
