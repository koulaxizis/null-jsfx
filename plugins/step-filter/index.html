Best uses

  • Rhythmic filter motion on pads and chords
  • Acid-style cutoff patterns on a bass line
  • Pulsing band-pass movement on drums or noise
  • Generated filter sequences to try ideas quickly

Properties

Signal chain: Input → state-variable filter (TPT, per channel) → Mix → Output. Up to 16 steps, one per Step Length at the host tempo and locked to the song position while the transport plays; each step sets the cutoff on a log scale between Low and High, with an optional raised-cosine glide. Seed draws 16 values with an exact Park-Miller generator, so the same Seed always plays the same sequence in every format. Resonance maps to Q 0.5-12; the cutoff stays below 0.45 of the sample rate. Stereo, zero latency.
