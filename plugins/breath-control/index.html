BREATH CONTROL

Vocal Breath Reduction

Download free Part of NULL JSFX 2.7: 126 plugins, free and open source (MIT). Easiest with NULL JSFX Hub.

Controls

  • Threshold−70 to 0 dB — Level (RMS-style, dBFS) below which the signal is treated as breath or noise and turned down; above it the voice passes at full level.
  • Attack1 to 50 ms — How fast the gain returns to unity when the voice comes back above Threshold.
  • Release20 to 1000 ms — How fast the gain moves down to Range once the level falls below Threshold.
  • Range−24 to 0 dB — How much quieter breaths get: the gain applied while the level is below Threshold.

Best uses

  • Turning down breaths between vocal phrases
  • Softening low-level noise in voice-over takes
  • Quick cleanup of podcast dialogue
  • Gentle alternative to a hard gate on vocals

Properties

Input → stereo-linked level detector (max of L/R, 1 ms rise / 30 ms fall) → compare with Threshold (3 dB hysteresis) → gain smoothed toward unity (Attack) or Range (Release) → applied to both channels → Output. No clipping; zero latency.
