NULL Tilt prototypes: the Tilt effect in its two extra forms
============================================================

Both sound identical (bit for bit) to NULL Tilt. Only the packaging differs.

1 - NULL Tilt GFX (JSFX)
    REAPER only. Copy both files, null_tilt_gfx.jsfx and null_gfx.jsfx-inc,
    into the same folder under the REAPER Effects folder (Options > Show
    REAPER resource path > Effects), rescan, then load "JS: NULL Tilt GFX".
    null_gfx.jsfx-inc holds the shared look and is not an effect by itself.

2 - NULL Tilt Native (VST3, CLAP)
    Any DAW. Install like any plugin:
      Windows: VST3 -> C:\Program Files\Common Files\VST3
               CLAP -> C:\Program Files\Common Files\CLAP
      macOS:   VST3 -> ~/Library/Audio/Plug-Ins/VST3
               CLAP -> ~/Library/Audio/Plug-Ins/CLAP
      Linux:   VST3 -> ~/.vst3     CLAP -> ~/.clap

macOS (not officially supported): these builds are not code-signed. If macOS
refuses to load them, run
    xattr -dr com.apple.quarantine <path to the .vst3/.clap>
and rescan the plugins.

Controls: drag the knob (Ctrl/Cmd or Shift for fine steps), double-click to
reset to 0, mouse wheel steps by 1. Drag the window corner to resize.
