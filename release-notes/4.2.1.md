## 4.2.1: lighter on silence

- **VST3/CLAP**: the native plugins no longer slow down on the silence after a sound. In hosts that leave denormal numbers on, decaying filter and reverb states made 42 plugins 3 to 40 times slower on those tails; the plugins now flush denormals while they run and give the host its own setting back. The sound is bit-identical
- **PRESET**: Band Spin's **Tremolo Bands** sits at a level closer to the other presets (Volume 60 instead of 80)
- **PRIVACY**: a privacy page (https://nulljsfx.tech/privacy/), licence notices of the third-party code in every package (`THIRD_PARTY_NOTICES.md`), and the Hub and the Android remotes now say what GitHub sees when they check for updates
- Every other plugin sounds exactly as in 4.2; only the version line changes
