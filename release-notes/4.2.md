## 4.2: Noise Reduction learns from a file

- **NOISE FILE** (beta): **NOISE REDUCTION** learns its noise profile from a WAV of room tone, hiss or hum in REAPER's `Data/null_jsfx_noise` folder (mono or stereo, any sample rate, the first 60 s), exactly as Learn would while that file plays. Turn **Use Noise File** On to use it; Off, or Clear in the plugin window, drops the profile. A new Learn replaces the file's profile, and Auto ignores it
- **SAVED PROFILE**: the profile in use, learnt or from the file, is now saved with the project and comes back without the file, in the JSFX, the VST3/CLAP and the Rack
- With Use Noise File Off (the default) Noise Reduction sounds exactly as in 4.1, and every other plugin is unchanged
- **SITE**: lighter and easier to tap on phones, its own page for addresses that do not exist, and the new 3D render and video of Noise Reduction
