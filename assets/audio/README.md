# NULL JSFX demo loop

`null-jsfx-loop.flac` (lossless) and `null-jsfx-loop.mp3` (256 kbps) are the same 60-second
instrumental loop: 120 BPM, A minor (Am, F, C, G), 48 kHz stereo, about -18.5 LUFS with
1.8 dB of headroom, a short fade-out in the last second. Drums, a filtered saw bass, a plucked
lead and a pad, all synthesized; no samples or recordings of anyone else.

It is the music in the NULL JSFX videos (the plugin presentations play it through each
plugin) and is meant to be shared by other projects as a neutral test and demo signal.
