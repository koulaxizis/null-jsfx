# Security policy

NULL JSFX is free, MIT licensed software made by one person. Security reports are welcome and
are handled with care.

## Supported versions

Only the latest release on https://github.com/koulaxizis/null-jsfx/releases gets fixes. A fix
ships as a new release, and NULL JSFX Hub and the Android remotes offer it as an update.

## Reporting a vulnerability

Please report it privately, not in a public issue:

- on GitHub: **Security > Report a vulnerability** in this repository (private vulnerability
  reporting is on), or
- by email to koulaxizis@glarolykoi.net, with "NULL JSFX security" in the subject.

Say which part is affected (a plugin and its format, the Hub, an installer, an Android remote, the
tablet remote or the website), the version, and how to reproduce it.

## What happens next

- You get an answer within 7 days.
- Within 30 days you hear whether the report is confirmed, and the plan to fix it.
- The fix is released before the details are made public. Until then the release notes say only
  "security fixes".
- You are credited in the release notes if you want to be.

Personal data is involved only in a narrow way (see https://nulljsfx.tech/privacy/): the project
keeps no accounts and no user data. If a report shows a breach of personal data, it is handled as
the privacy page and the GDPR require, including a notice to the Hellenic Data Protection
Authority within 72 hours where needed.
