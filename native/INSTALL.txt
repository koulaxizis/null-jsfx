NULL JSFX: installation
=======================

Every plugin comes in up to three versions that sound the same:

  JSFX        REAPER only, REAPER's own sliders (the original)
  JSFX GFX    REAPER only, with its own interface ("NULL <Name> GFX")
  VST3, CLAP  any DAW, with the same interface ("<Name>" by NULL JSFX)

JSFX (REAPER), from NULL-JSFX-JSFX.zip
    Copy the folder null_jsfx into REAPER's Effects folder (Options >
    Show REAPER resource path > Effects), then rescan in the FX browser. Keep
    the gfx folder inside it together: gfx/null_gfx.jsfx-inc holds the shared
    look of the GFX versions and is not an effect by itself.
    Font: the GFX versions use Noto Sans (included in the fonts folder, free
    under the SIL Open Font License). Install NotoSans-Regular.ttf and
    NotoSans-Bold.ttf (double-click > Install) so they look exactly like the
    VST3/CLAP versions; without it REAPER falls back to a system font.

FX chains (REAPER), from NULL-JSFX-JSFX.zip
    Ready-made chains of NULL JSFX plugins (Vocal Chain, Mastering Chain, Guitar
    Amp, Lo-Fi and more). Copy the two folders inside FXChains ("NULL JSFX" with
    the plain JSFX, "NULL JSFX GFX" with the GFX versions) into REAPER's
    FXChains folder (Options > Show REAPER resource path > FXChains). They need
    the null_jsfx folder installed as above. In REAPER: FX window > FX >
    Add FX chain, or the FX Chains folder of the FX browser.

VST3 and CLAP (any DAW), from NULL-JSFX-VST3-CLAP-<your OS>.zip
    Copy the "NULL JSFX" folder from VST3 and from CLAP to:
      Windows: C:\Program Files\Common Files\VST3
               C:\Program Files\Common Files\CLAP
      macOS:   ~/Library/Audio/Plug-Ins/VST3
               ~/Library/Audio/Plug-Ins/CLAP
      Linux:   ~/.vst3   and   ~/.clap
    then rescan plugins in your DAW.

Rack (any DAW), in the VST3 and CLAP folders
    "Rack" by NULL JSFX chains up to 8 NULL JSFX effects in one plugin, with
    band splitting (Low/Mid/High), Mid/Side or Left/Right processing per slot,
    8 macros, 2 LFOs and an envelope follower. Its presets include the FX
    chains above and a few that only the Rack can do (Multiband Distortion,
    Mid/Side EQ, Auto Filter and more). It installs with the other plugins.

Presets
    Every plugin has the same factory presets in all versions. JSFX: REAPER's
    preset menu at the top of the FX window (they come from the .rpl file next
    to each plugin; keep it there). GFX, VST3 and CLAP: the box at the top
    right of the interface; the arrows step through the presets, a click on the
    name opens the list. It shows CUSTOM once you change a control. Your own
    presets are saved with your DAW's preset menu as usual.

macOS (not officially supported): the builds are not code-signed. If macOS
refuses to load them, run
    xattr -dr com.apple.quarantine <path to the .vst3/.clap>
and rescan.

Controls: drag the slider sideways (Ctrl/Cmd or Shift for fine steps),
double-click to reset, mouse wheel steps by 1. Resize the window from its
edge or corner.
