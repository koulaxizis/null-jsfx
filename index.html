Release Notes v2.0

October 8, 2026

73 PLUGINS IN THREE CATEGORIES

  • ONE SLIDER (20): one control, instant result
  • ESSENTIALS (31): the everyday mixing and mastering toolbox
  • ADVANCED (22): sound design, creative effects and special processing

NEW FORMATS

  • All 20 ONE SLIDER plugins now come in three versions that sound the same: the original JSFX, a GFX version with its own interface, and VST3 / CLAP for any DAW on Windows, macOS and Linux
  • One shared look across the GFX and VST3/CLAP versions: a live display (response curve, transfer curve, meters or scope) above a single slider

NEW

  • 53 new plugins, including Convolution, Spring Reverb, Shimmer Reverb, Harmonizer, Vocoder, Spectral Freeze, Granular Delay, OTT, Frequency Shifter, Rotary Speaker, Robotizer, Cabinet Simulator, Sidechain Ducker, Riser, Auto-Leveler and Envelope Follower
  • Single-purpose v1.0 tools are merged into their full versions: Tape Saturation, Harmonic Drive, Distortion and Bit Crush now live in SATURATION; the 5-Band EQ is now PARAMETRIC EQ

FIXES

  • Sample-rate math fixed across the suite: filters, envelopes and delay times now behave the same at 44.1, 48 and 96 kHz
  • Every plugin is rendered by an automated test at three sample rates and extreme settings before release; every GFX and VST3/CLAP version is checked to sound identical to its JSFX
  • Uniform plugin header: name, author, tags, category and version on every file

PROPERTIES

  • Pure EEL2 scripting, zero external dependencies
  • Native Reaper sliders for maximum stability
  • CPU-efficient design for real-time processing
  • Free and open source

Plugins

HOW TO
1

Install Effects

Download JSFX for REAPER and extract the null_jsfx folder to your Reaper Effects directory:

Windows
C:/Users/[Username]/AppData/Roaming/REAPER/Effects/
macOS
~/Library/Application Support/REAPER/Effects/
Linux
~/.config/REAPER/Effects/

Restart Reaper or re-scan your plugins folders. NULL JSFX will be available under the JS category in the FX browser. Keep the gfx folder inside it: it holds the GFX versions (NULL <Name> GFX) and the file that draws their interface.

+

VST3 and CLAP (any DAW)

Plugins marked VST3 and CLAP also come as regular plugins. Download VST3 & CLAP for your system and copy the NULL JSFX folders from its VST3 and CLAP folders to:

Windows
C:/Program Files/Common Files/VST3/ and C:/Program Files/Common Files/CLAP/
macOS
~/Library/Audio/Plug-Ins/VST3/ and ~/Library/Audio/Plug-Ins/CLAP/
Linux
~/.vst3/ and ~/.clap/

Rescan plugins in your DAW. They appear under their own names (e.g. Tilt) with NULL JSFX as the maker.

2

Load Plugins

  1. Click the FX button on any track
  2. Open the FX Browser (if not visible)
  3. Navigate to the JS category
  4. Find plugins under JS: NULL JSFX folder
  5. Select any plugin to load it
💡 Tip: To see all plugins organized in the FX explorer, filter by searching "NULL" or create a Smart Folder: Menu "View" → FX Browser → right-click on "Folders" → "Add folder" → "Smart folder" → Filter contains "NULL". They will auto-categorize!
🎤 Shortcut: Press / to quickly focus the plugin search bar. ESC closes all modals.
