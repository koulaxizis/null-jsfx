Release Notes v1.0

July 25, 2026

INITIAL RELEASE

  • Added 24 JSFX units for recording, mixing and mastering — useful for professionals and amateur audio engineers and musicians

PLUGINS

  • 5-BAND PARAMETRIC EQ — Flexible multi-filter EQ with 8 filter types per band
  • CHANNEL UTILITY — All-in-one channel tool with phase, DC block, mono check
  • STEREO WIDTH — Mid/Side imaging with frequency crossover
  • FILTER — TPT State-Variable Lowpass with resonance
  • TAPE SATURATION — Vintage warmth and glue
  • HARMONIC DRIVE — Even-order exciter
  • DISTORTION — Aggressive dual-stage overdrive
  • BIT CRUSH — Lo-fi quantization and downsampling
  • CHORUS — Stereo thickening and detune
  • FLANGER — Jet sweep with feedback
  • PHASER — Moving notch sweep with 1-8 stages
  • VIBRATO — Pitch modulation wobble
  • TREMOLO — Rhythmic amplitude modulation
  • AUTO PAN — Stereo movement with tempo sync
  • RING MOD — Metallic carrier modulation
  • GATE — Noise and vocal gate with sidechain HPF
  • DYNAMICS — Compressor and expander
  • LIMITER — Limiter, clipper, and brickwall modes
  • DELAY — Echo and pre-delay
  • CLICK REPAIR — Audio restoration
  • DEESSER — Sibilance reduction
  • PITCH SHIFTER — Real-time pitch shift with octave/semitone/cents
  • REVERB — Space and ambience
  • TRANSIENT SHAPER — Attack and sustain control

PROPERTIES

  • Pure EEL2 scripting — zero external dependencies
  • Native Reaper sliders for maximum stability
  • Carbon (#232323) visual theme across all plugins
  • CPU-efficient design for real-time processing
  • Free and open source

Individual Plugins

HOW TO
1

Install Effects

After downloading, extract the null-jsfx folder to your Reaper Effects directory:

Windows
C:/Users/[Username]/AppData/Roaming/REAPER/Effects/
macOS
~/Library/Application Support/REAPER/Effects/
Linux
~/.config/REAPER/Effects/

Restart Reaper or re-scan your plugins folders. NULL JSFX will be available under the JS category in the FX browser.

2

Load Plugins

  1. Click the FX button on any track
  2. Open the FX Browser (if not visible)
  3. Navigate to the JS category
  4. Find plugins under JS: NULL JSFX folder
  5. Select any plugin to load it
3

FX Chains (Optional)

Copy .RfxChain files to your FXChains folder:

  1. Windows: C:/Users/[Username]/AppData/Roaming/REAPER/FXChains/
  2. macOS: ~/Library/Application Support/REAPER/FXChains/
  3. In Reaper's FX Window, go to FX Chains category
  4. Double-click any chain to load all plugins automatically
⚠ Important: Plugins must be installed in Effects/null-jsfx/ subfolder for chains to work properly.
💡 Tip: To see all plugins organized in the FX explorer, filter by searching "NULL" or create a Smart Folder: Menu "View" → FX Browser → right-click on "Folders" → "Add folder" → "Smart folder" → Filter contains "NULL". They will auto-categorize!
🎤 Shortcut: Press / to quickly focus the plugin search bar. ESC closes all modals.
