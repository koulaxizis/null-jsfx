# orOS fonts

- **Nunito** (`Nunito.ttf`, variable 200–1000, licence `OFL.txt`): the orOS font for Latin text and the wordmark.
- **M PLUS Rounded 1c, Greek subset** (`MPLUSRounded1c-Greek-*.ttf`, licence `OFL-MPLUSRounded1c.txt`): Nunito has no Greek, so orOS draws Greek with this rounded companion (Regular, Medium, Bold, ExtraBold), as the orOS app does.

For Greek text set Nunito with M PLUS Rounded 1c as the fallback font, or use M PLUS Rounded 1c for the Greek passages.
