# Τρία δωρεάν projects ανοιχτού κώδικα: NULL JSFX, orOS και noxpress

**Για άμεση δημοσίευση · 2 Νοεμβρίου 2026**

Ο Χρήστος Κουλαξίζης φτιάχνει τρία δωρεάν projects ανοιχτού κώδικα με κοινή ιδέα: χρήσιμο λογισμικό χωρίς paywalls, διαφημίσεις, κλειδιά άδειας ή tracking, που στηρίζεται μόνο σε εθελοντική υποστήριξη στο Ko-fi.

- **NULL JSFX** (nulljsfx.tech): 150 plugins ήχου για το REAPER και κάθε DAW, ως JSFX, GFX JSFX, VST3, CLAP και modules για το Rack, με presets, αλυσίδες εφέ και εφαρμογή Hub.
- **orOS** (useoros.online): ένα στατικό λειτουργικό σύστημα στον browser με 132 εφαρμογές, που δουλεύει χωρίς σύνδεση, σέβεται την ιδιωτικότητα και εγκαθίσταται σε Windows, Linux, Android και USB stick.
- **noxpress** (noxpress.tech): 32 plugins για WordPress και WooCommerce, για καταστήματα και εκδότες, με ένα hub και υπογεγραμμένες ενημερώσεις.

Και τα τρία έχουν άδεια MIT, αναπτύσσονται ανοιχτά στο GitHub (github.com/koulaxizis) και είναι διαθέσιμα στα αγγλικά και στα ελληνικά.

**Media kit:** λογότυπα, banners, wallpapers, παλέτες, γραμματοσειρές και αρχεία εκτύπωσης κατεβαίνουν ελεύθερα από το site κάθε project.
