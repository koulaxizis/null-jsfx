# Τέσσερα δωρεάν projects ανοιχτού κώδικα: NULL JSFX, orOS, noxpress και Waymark

**Για άμεση δημοσίευση · 21 Νοεμβρίου 2026**

Ο Χρήστος Κουλαξίζης φτιάχνει τέσσερα δωρεάν projects ανοιχτού κώδικα με κοινή ιδέα: χρήσιμο λογισμικό χωρίς paywalls, διαφημίσεις, κλειδιά άδειας ή tracking, που στηρίζεται σε αγορές προϊόντων των projects, εφάπαξ δωρεές και πληρωμένες υπηρεσίες, χωρίς να ξεκλειδώνει τίποτα.

- **NULL JSFX** (nulljsfx.tech): 168 plugins ήχου για το REAPER και κάθε DAW, ως JSFX, GFX JSFX, VST3, CLAP, LV2 και modules για το Rack, με presets, αλυσίδες εφέ και εφαρμογή Hub.
- **orOS** (useoros.online): ένα στατικό λειτουργικό σύστημα στον browser με 140 εφαρμογές, που δουλεύει χωρίς σύνδεση, σέβεται την ιδιωτικότητα και εγκαθίσταται σε Windows, Linux, Android και USB stick.
- **noxpress** (noxpress.tech): 48 plugins για WordPress και WooCommerce, για καταστήματα και εκδότες, με ένα hub και υπογεγραμμένες ενημερώσεις.
- **Waymark** (waymarked.site): ελαφριά, portable εργαλεία για ηχοληψία, οπτικοακουστικά και συνέδρια, που τρέχουν τοπικά και offline μέσα από το δίκτυο του χώρου. Σε σχεδιασμό, χωρίς έκδοση ακόμη· πρώτο εργαλείο το Waymark Remote.

Και τα τέσσερα έχουν άδεια MIT, αναπτύσσονται ανοιχτά στο GitHub (github.com/koulaxizis) και είναι διαθέσιμα στα αγγλικά και στα ελληνικά.

**Media kit:** λογότυπα, banners, wallpapers, παλέτες, γραμματοσειρές και αρχεία εκτύπωσης κατεβαίνουν ελεύθερα από το site κάθε project.
