# NULL JSFX 3.0: 150 free audio plugins for REAPER and every DAW

**For immediate release · 2 November 2026**

NULL JSFX is a free, open-source (MIT) suite of audio plugins with the slogan "Audio without noise". Version 3.0 brings the suite to 150 plugins in six categories: One Slider, Essentials, Advanced, Assisted (beta), Instruments and MIDI.

Every plugin ships in several forms that sound identical, checked by automated tests:

- plain JSFX for REAPER, written in pure EEL2, the base of the suite;
- GFX JSFX with a resizable dark interface, knobs, curves and meters;
- native VST3 and CLAP plugins for any DAW on Windows, Linux and macOS;
- Rack modules, factory presets and ready-made REAPER FX chains.

The NULL JSFX Hub installs, updates and removes the suite with one click, and installers are available for each operating system. Everything downloads from the project's GitHub releases. There are no accounts, licence keys, ads or paid tiers.

> "I wanted a complete set of studio tools that anyone can use and study, without paywalls. NULL JSFX stays free, and the code stays open." (Christos Koulaxizis, creator)
