# NULL JSFX 3.0: 150 δωρεάν plugins ήχου για το REAPER και κάθε DAW

**Για άμεση δημοσίευση · 2 Νοεμβρίου 2026**

Το NULL JSFX είναι μια δωρεάν σουίτα plugins ήχου ανοιχτού κώδικα (MIT) με σύνθημα «Audio without noise». Η έκδοση 3.0 φτάνει τα 150 plugins σε έξι κατηγορίες: One Slider, Essentials, Advanced, Assisted (beta), Instruments και MIDI.

Κάθε plugin διατίθεται σε πολλές μορφές που ακούγονται πανομοιότυπα, κάτι που ελέγχεται με αυτόματα τεστ:

- απλό JSFX για το REAPER, γραμμένο σε καθαρό EEL2, η βάση της σουίτας·
- GFX JSFX με σκούρο περιβάλλον που αλλάζει μέγεθος, κουμπιά, καμπύλες και μετρητές·
- εγγενή plugins VST3 και CLAP για κάθε DAW σε Windows, Linux και macOS·
- modules για το Rack, εργοστασιακά presets και έτοιμες αλυσίδες εφέ για το REAPER.

Το NULL JSFX Hub εγκαθιστά, ενημερώνει και αφαιρεί τη σουίτα με ένα κλικ, και υπάρχουν installers για κάθε λειτουργικό σύστημα. Όλα κατεβαίνουν από τα GitHub releases του project. Δεν υπάρχουν λογαριασμοί, κλειδιά άδειας, διαφημίσεις ή επί πληρωμή εκδόσεις.

> «Ήθελα ένα πλήρες σετ εργαλείων στούντιο που μπορεί να χρησιμοποιήσει και να μελετήσει ο καθένας, χωρίς paywalls. Το NULL JSFX μένει δωρεάν και ο κώδικας ανοιχτός.» (Χρήστος Κουλαξίζης, δημιουργός)
