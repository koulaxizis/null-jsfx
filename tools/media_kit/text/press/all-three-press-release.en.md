# Three free, open-source projects: NULL JSFX, orOS and noxpress

**For immediate release · 18 November 2026**

Christos Koulaxizis builds three free, open-source projects that share one idea: useful software without paywalls, ads, licence keys or tracking, supported by merch, one-time donations and paid services, with nothing unlocked.

- **NULL JSFX** (nulljsfx.tech): 168 audio plugins for REAPER and every DAW, as JSFX, GFX JSFX, VST3, CLAP, LV2 and Rack modules, with presets, FX chains and a Hub app.
- **orOS** (useoros.online): a static operating system in the browser with 140 apps, offline-first, private by design, installable on Windows, Linux, Android and a USB stick.
- **noxpress** (noxpress.tech): 48 WordPress and WooCommerce plugins for shops and publishers, managed from one hub with signed updates.

All three are MIT-licensed, developed in the open on GitHub (github.com/koulaxizis) and available in English and Greek.

**Media kit:** logos, banners, wallpapers, palettes, fonts and print files are free to download from each project's site.
