# Waymark: free, offline tools for sound engineering, AV and conferences, now in design

**For immediate release · 21 November 2026**

Waymark is a new free, open-source (MIT) suite of lightweight tools for sound engineering, AV and conferences, by Christos Koulaxizis. Its tagline: "Tools that keep the show on track." Waymark is in design; there is no release and nothing to download yet.

- **Portable:** one file per system or a web page; no installer, no admin rights, runs from USB.
- **Local and offline:** devices talk over the venue's own network and presentations never leave it; no cloud server, accounts, cookies, telemetry, ads or paid services.
- **First tool, Waymark Remote:** Secretariat, Operator and Overview roles to open, check and control presentations and send files to every room, with a built-in presentation check that fixes only a copy, and pairing, a visible indicator, one-click disconnect and encryption on the speaker's laptop.
- **Planned steps, no dates:** 0.1 presentations and files, 0.2 screen view and Agent Lite, 0.3 full remote control. Planned for Windows, macOS, Linux, Android and iPhone/iPad in the browser.
