# NULL JSFX · orOS · noxpress media kit

Free logos, wallpapers, banners, print files, palettes, fonts and press texts.

- `wallpapers/`: dark, three styles (`mark`, `pattern`, `minimal`), sizes 4K, 5K, 16:10, ultrawide, Android, iPhone and tablet (JPEG).
- `logos/`: icon (512–4096 px), single-colour marks, horizontal and stacked logos for dark backgrounds, plus white and black single-colour versions (PNG, transparent), and `svg/` sources.
- `banners/`: Open Graph, Ko-fi / X header, YouTube, Facebook, LinkedIn, GitHub social preview, avatar (PNG).
- `print/`: Printful-ready t-shirt, mug and sticker files (see `print/README.md`).
- `palettes/`: `.ase`, `.gpl`, `.css`, `.json`, swatch card.
- `fonts/`: the brand font with its OFL licence (orOS: Nunito plus its Greek companion, M PLUS Rounded 1c).
- `press/`: press releases in English and Greek.
- `brand-guidelines.en.md` / `.el.md` and `LICENSE-media-kit.md`.
