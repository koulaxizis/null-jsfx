## Long

Waymark is a free, open-source (MIT) suite of lightweight tools for sound engineering, AV and conferences, made by Christos Koulaxizis and built first for real events. Its tagline is "Tools that keep the show on track."

Every Waymark tool is a portable app (one file per system) or a web page: nothing to install, no admin rights, and it runs from a USB stick. Devices talk directly over the venue's local network, so presentation content never leaves it. There is no cloud server and there are no accounts, cookies, telemetry, ads or paid services. The tools come with a dark theme by default and a light one, in Greek and English, with a 24-hour clock.

The first tool is **Waymark Remote**, a minimal remote tool that connects operator, secretariat and speaker computers over any local network, wired or wireless, to open, check and control presentations and transfer files, without installing anything on the speaker's computer. It has three roles: Secretariat (sends files to rooms and sees their status), Operator (opens and runs the presentation from a laptop or an Android phone) and Overview (watches every room and can take over). A built-in check runs on the laptop that will play the file and looks for missing fonts, videos, slides that fail and the screen ratio; fixes are made only on a copy. Pairing is required on the speaker's laptop, a visible indicator shows the connection, one click disconnects, and traffic is encrypted and stays on the LAN.

Planned steps, with no dates yet: 0.1 presentation control and file transfer; 0.2 screen view and Agent Lite, a browser-only agent; 0.3 full remote control. Planned platforms: Windows (exe), macOS (.app), Linux (AppImage), Android (APK) and iPhone/iPad in the browser, unsigned for now. Later tools cover time and speakers, presenting and playout, presentation, PDF and media checks, crew and sound tools, and Waymark Kit for equipment checklists.

Waymark is in design. There is no release and nothing to download yet.
