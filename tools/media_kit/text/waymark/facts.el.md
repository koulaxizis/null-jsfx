# Waymark: φύλλο στοιχείων

| | |
|---|---|
| Όνομα | Waymark |
| Τι είναι | Δωρεάν σειρά ελαφριών εργαλείων ανοιχτού κώδικα για ηχοληψία, οπτικοακουστικά και συνέδρια |
| Σύνθημα | Εργαλεία που κρατούν την εκδήλωση στην ώρα της. |
| Δημιουργός | Χρήστος Κουλαξίζης |
| Άδεια | MIT· δωρεάν για πάντα, τίποτα δεν ξεκλειδώνει με αγορά ή δωρεά |
| Κατάσταση | Σε σχεδιασμό, χωρίς έκδοση ακόμη, χωρίς λήψεις |
| Site | waymarked.site |
| Κώδικας | github.com/koulaxizis/waymark |
| Πρώτο εργαλείο | Waymark Remote: ρόλοι Γραμματεία, Χειριστής (laptop ή κινητό Android), Εποπτεία· ενσωματωμένος έλεγχος παρουσίασης, διορθώσεις μόνο σε αντίγραφο· σύζευξη, ορατή ένδειξη, αποσύνδεση με ένα κλικ, κρυπτογράφηση, μόνο τοπικό δίκτυο |
| Βήματα (χωρίς ημερομηνίες) | 0.1 παρουσιάσεις και αρχεία · 0.2 προβολή οθόνης και Agent Lite (μόνο στον browser) · 0.3 πλήρης απομακρυσμένος χειρισμός |
| Πλατφόρμες (σχέδιο) | Windows exe, macOS .app, Linux AppImage, Android APK, iPhone/iPad στον browser· χωρίς υπογραφή προς το παρόν |
| Αρχές | Μόνο portable εφαρμογές και web, χωρίς εγκατάσταση ή δικαιώματα διαχειριστή, τρέχει από USB· τοπικά και offline μέσα από το δίκτυο του χώρου· χωρίς cloud, λογαριασμούς, cookies, telemetry, διαφημίσεις ή πληρωμένες υπηρεσίες |
| Γλώσσες και θέματα | Ελληνικά και αγγλικά· σκούρο θέμα από προεπιλογή και ανοιχτό· ρολόι 24 ωρών |
| Ταυτότητα | Πράσινο pine #01796F· λευκή καρφίτσα χάρτη σε πράσινο κύκλο· Inter |
| Υποστήριξη | waymarked.site/support/ |
| Επικοινωνία | Χρήστος Κουλαξίζης, μέσω του koulaxizis.gr |
