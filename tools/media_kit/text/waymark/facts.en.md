# Waymark: facts sheet

| | |
|---|---|
| Name | Waymark |
| What | Free, open-source suite of lightweight tools for sound engineering, AV and conferences |
| Tagline | Tools that keep the show on track. |
| Made by | Christos Koulaxizis |
| Licence | MIT; free forever, nothing is unlocked by buying or donating |
| Status | In design, no release yet, no downloads |
| Site | waymarked.site |
| Source | github.com/koulaxizis/waymark |
| First tool | Waymark Remote: roles Secretariat, Operator (laptop or Android phone), Overview; built-in presentation check, fixes on a copy only; pairing, visible indicator, one-click disconnect, encrypted, LAN only |
| Planned steps (no dates) | 0.1 presentations and files · 0.2 screen view and Agent Lite (browser-only) · 0.3 full remote control |
| Planned platforms | Windows exe, macOS .app, Linux AppImage, Android APK, iPhone/iPad browser; unsigned for now |
| Principles | Portable apps and the web only, no installer or admin rights, runs from USB; local and offline over the venue network; no cloud server, accounts, cookies, telemetry, ads or paid services |
| Languages and themes | Greek and English; dark theme by default plus light; 24-hour clock |
| Brand | Pine green #01796F; white map pin in a green circle; Inter |
| Support | waymarked.site/support/ |
| Contact | Christos Koulaxizis, via koulaxizis.gr |
