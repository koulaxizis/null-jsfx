1Stereo Width

  • Width90%

Modulation

  • Envelope moves Stereo Width · Width by +45% (follows the input level, attack 5 ms, release 250 ms)

In REAPER an LFO is a parameter modulation and the envelope an audio control signal on the control it moves. The Rack preset of the same name has them as real LFOs, envelope and macro knobs.

Load it

  1. Install NULL JSFX with the Hub or the JSFX download: the chains come in its FXChains folder.
  2. In REAPER, open a track's FX window and pick FX → Add FX chain, then NULL JSFX (REAPER's sliders) or NULL JSFX GFX (our interfaces), then Dynamic Width.
  3. In any other DAW: load the NULL JSFX Rack (VST3 or CLAP) and pick its preset Dynamic Width.
