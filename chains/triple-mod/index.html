The settings

What the chain changes from each plugin's defaults. Every control stays free to change after you load it.

1Phaser

  • Rate0.3 Hz
  • Stages4
  • Mix15%

2Flanger Side

  • Rate0.2 Hz
  • Depth3 ms
  • Feedback30%
  • Mix15%

3Chorus

  • Rate0.6 Hz
  • Depth3 ms
  • Mix15%

4Auto Pan

  • Rate0.2 Hz
  • Depth30%
  • Mix20%

Modulation

  • Macro 1 moves Phaser · Mix by +45%
  • Macro 1 moves Flanger · Mix by +45%
  • Macro 1 moves Chorus · Mix by +45%
  • LFO 1 moves Phaser · Rate by +10% (Triangle, 0.05 Hz)
  • LFO 2 moves Flanger · Depth by +20% (Random, 0.2 Hz)

In REAPER an LFO is a parameter modulation and the envelope an audio control signal on the control it moves; a macro is the control with the largest depth, and the others follow it through parameter links. The Rack preset of the same name has them as real LFOs, envelope and macro knobs.

Load it

  1. Install NULL JSFX with the Hub or the JSFX download: the chains come in its FXChains folder.
  2. In REAPER, open a track's FX window and pick FX → Add FX chain, then NULL JSFX (REAPER's sliders) or NULL JSFX GFX (our interfaces), then Triple Mod.
  3. In any other DAW: load the NULL JSFX Rack (VST3 or CLAP) and pick its preset Triple Mod.
