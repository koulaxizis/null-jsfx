The settings

What the chain changes from each plugin's defaults. Every control stays free to change after you load it.

1Octaver Low

  • Dry100%

  • Up0%
  • Tone400 Hz
  • Tracking150 Hz

2Sub Bloom Low

  • Source Frequency80 Hz
  • Sub Level15%
  • Original Mix100%

3Mono Maker Low

  • Amount100

Modulation

  • Macro 1 moves Octaver · Oct -1 by +40%
  • Macro 1 moves Sub Bloom · Sub Level by +30%
  • Macro 2 moves Octaver · Oct -2 by +40%

In REAPER an LFO is a parameter modulation and the envelope an audio control signal on the control it moves; a macro is the control with the largest depth, and the others follow it through parameter links. The Rack preset of the same name has them as real LFOs, envelope and macro knobs.

Load it

  1. Install NULL JSFX with the Hub or the JSFX download: the chains come in its FXChains folder.
  2. In REAPER, open a track's FX window and pick FX → Add FX chain, then NULL JSFX (REAPER's sliders) or NULL JSFX GFX (our interfaces), then Sub Harmonics.
  3. In any other DAW: load the NULL JSFX Rack (VST3 or CLAP) and pick its preset Sub Harmonics.
