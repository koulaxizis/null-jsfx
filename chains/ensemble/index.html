Load it

  1. Install NULL JSFX with the Hub or the JSFX download: the chains come in its FXChains folder.
  2. In REAPER, open a track's FX window and pick FX → Add FX chain, then NULL JSFX (REAPER's sliders) or NULL JSFX GFX (our interfaces), then Ensemble.
  3. In any other DAW: load the NULL JSFX Rack (VST3 or CLAP) and pick its preset Ensemble.
