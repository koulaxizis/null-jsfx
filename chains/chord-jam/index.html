CHORD JAM

Chords generates a minor progression that advances every bar on its own, played by strings with chorus and reverb.

The settings

What the chain changes from each plugin's defaults. Every control stays free to change after you load it.

1Chords

  • GenerateOn
  • Generate Seed42
  • Generate MoodMinor
  • Auto AdvanceEvery 4 Beats
  • Chord Type7th
  • VoicingOpen

2String Ensemble

  • Attack300 ms
  • Release1500 ms

3Chorus

  • Rate0.5 Hz
  • Depth4 ms
  • Mix30%

4Reverb

  • Room Size70%
  • Decay60%
  • Mix25%

Load it

  1. Install NULL JSFX with the Hub or the JSFX download: the chains come in its FXChains folder.
  2. In REAPER, open a track's FX window and pick FX → Add FX chain, then NULL JSFX (REAPER's sliders) or NULL JSFX GFX (our interfaces), then Chord Jam.
