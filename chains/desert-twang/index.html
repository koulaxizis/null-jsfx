Modulation

  • Macro 1 moves Spring Reverb · Mix by +20%
  • Macro 1 moves Delay · Mix by +20%
  • Macro 1 moves Tremolo · Depth by +40%
  • Macro 2 moves Amp Simulator · Gain by +40%
  • Macro 2 moves Amp Simulator · Master by -20%

In REAPER an LFO is a parameter modulation and the envelope an audio control signal on the control it moves; a macro is the control with the largest depth, and the others follow it through parameter links. The Rack preset of the same name has them as real LFOs, envelope and macro knobs.

Load it

  1. Install NULL JSFX with the Hub or the JSFX download: the chains come in its FXChains folder.
  2. In REAPER, open a track's FX window and pick FX → Add FX chain, then NULL JSFX (REAPER's sliders) or NULL JSFX GFX (our interfaces), then Desert Twang.
  3. In any other DAW: load the NULL JSFX Rack (VST3 or CLAP) and pick its preset Desert Twang.
