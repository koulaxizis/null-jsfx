LO-FI KEYS

A lo-fi electric piano for beats: tine keys with a little tremolo, squashed and bit-reduced by Lo-Fi Comp, then vinyl crackle, worn tape and a small room.

Load it

  1. Install NULL JSFX with the Hub or the JSFX download: the chains come in its FXChains folder.
  2. In REAPER, open a track's FX window and pick FX → Add FX chain, then NULL JSFX (REAPER's sliders) or NULL JSFX GFX (our interfaces), then Lo-Fi Keys.
