ACID LINE

A ready acid line on one track: Riff writes the notes from Key, Scale and Seed, the Bass plays them with glide and a resonant envelope, then a driven filter, tube saturation and a dotted-eighth delay.

Load it

  1. Install NULL JSFX with the Hub or the JSFX download: the chains come in its FXChains folder.
  2. In REAPER, open a track's FX window and pick FX → Add FX chain, then NULL JSFX (REAPER's sliders) or NULL JSFX GFX (our interfaces), then Acid Line.
