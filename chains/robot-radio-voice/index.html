The settings

What the chain changes from each plugin's defaults. Every control stays free to change after you load it.

1Pitch Correction

  • Retune Speed0 ms
  • Humanize0%

2Robotizer

  • Pitch120 Hz
  • Metallic30%
  • Mix70%

3Formant Filter

  • VowelI
  • Q8

4Filter

  • Cutoff1000 Hz
  • Resonance0.5
  • ModeBand Pass

5Saturation

  • Drive60%
  • Mix100%
  • ModeTube

6Spring Reverb

  • Mix15%

Modulation

  • LFO 1 moves Formant Filter · Vowel by +50% (Sine, 0.2 Hz)

In REAPER an LFO is a parameter modulation and the envelope an audio control signal on the control it moves. The Rack preset of the same name has them as real LFOs, envelope and macro knobs.

Load it

  1. Install NULL JSFX with the Hub or the JSFX download: the chains come in its FXChains folder.
  2. In REAPER, open a track's FX window and pick FX → Add FX chain, then NULL JSFX (REAPER's sliders) or NULL JSFX GFX (our interfaces), then Robot Radio Voice.
  3. In any other DAW: load the NULL JSFX Rack (VST3 or CLAP) and pick its preset Robot Radio Voice.
